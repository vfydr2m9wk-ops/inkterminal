InkDOS Hub iPhone → Zoom

INKDOSHUB WEBCAM · OPTION B

Use the iPhone rear camera in Zoom

The reliable route is to make the iPhone feed a camera device that the computer operating system exposes to Zoom. InkDOS Hub already contains a Windows virtual-camera app for this purpose.

Recommended: Windows + InkDOS Hub Webcam

No OBS installation is required. The Windows app receives the iPhone stream and exposes it as a camera named “InkDOS Hub Webcam”.

1 · Download the Windows app

On a Windows 10/11 computer (64-bit), download the ZIP and extract the entire folder. Do not run the EXE from inside the ZIP.

Download InkDOS Hub Webcam (ZIP)
2 · Open the receiver

Run “InkDOS Hub Webcam.exe”. On first launch, approve the administrator prompt so Windows can register the virtual camera. Keep the app open during the meeting.

3 · Pair the iPhone

In the app’s embedded Webcam page, use the Guest/receiver view and note the six-character code or QR code. On the iPhone, open the InkDOS Hub Webcam page, choose Host, scan/type the code, select Back camera and start the stream. Keep Safari open and the screen awake.

Open InkDOS Hub Webcam
4 · Select the camera in Zoom

In the Zoom desktop app on Windows, open Settings → Video and select “InkDOS Hub Webcam”. Preview the image before joining the call. The receiver app must remain running.

Zoom camera requirements

Important: this does not make the iPad’s Zoom use the feed

The computer is part of this solution.

If Zoom remains open on the iPad in Safari, it will still use a camera device available to iPadOS. A webpage cannot register InkDOS Hub’s received stream as a system camera on the iPad. For the iPhone image to be sent as the camera in a normal Zoom meeting, run that meeting on the computer and select the virtual camera there.

Quality settings

  • Start with 1080p 30 fps for stability; try 1080p 60 fps if the computer and network handle it well.
  • 4K is not needed for a normal Zoom call and can increase processing and network load. The Zoom desktop app may limit the outgoing resolution based on the account, meeting, and device.
  • Use the same reliable Wi-Fi network for both devices when possible. The video uses WebRTC; the public PeerJS service is used for pairing/signaling.

Alternative: OBS Virtual Camera

If the Windows app fails to create or expose its camera, use OBS Studio: add the InkDOS Hub Guest page as a Browser source, then start OBS Virtual Camera and select “OBS Virtual Camera” in Zoom. This alternative is documented on the main Webcam page.
